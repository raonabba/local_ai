# 반영된 공문서 작성 규칙

출처: 「공문서 작성법 길라잡이」(2025. 1. 8.). 원문은 저작권 대상이라 이 저장소에 싣지 않고,
규칙만 요약해 프로그램에 반영했습니다. 원문을 제품에 그대로 넣거나 배포하려면 저작권자의 허락이 필요합니다.

표의 **자동**은 교정에서 바로 고치는 것, **안내**는 사람이 판단하도록 알려 주는 것, **AI**는 초안·톤 조정 때 AI에 주는 지침입니다.

## 표기법

| 대상 | 규칙 | 처리 |
|---|---|---|
| 날짜 | `2025. 1. 6.` 형식, '일' 뒤에도 마침표. `’24.`처럼 줄여 쓰지 않음 | 자동 |
| 요일 | `2025. 1. 6.(월)` (마침표 뒤에 괄호) | 자동 |
| 기간 | `2025. 2. 20.~2. 24.` (끝 날짜에도 월), 물결표와 '까지'를 함께 쓰지 않음 | 자동 |
| 시각 | 24시각제, `09:00`처럼 0을 넣고 쌍점은 붙여 씀. 시만 쓸 때는 `09시`, `14시` | 자동 |
| 모호한 시각 | `3시`, `밤 12시`, `24시까지` | 안내 |
| 금액 | `금113,560원(금일십일만삼천오백육십원)`, 계약서의 `일금-원정`은 그대로 | 자동 |
| 외국 문자 | 우리말 뒤 괄호에: `연구 개발(R&D)`, `1층`, `묻고 답하기` | 자동 |

## 항목과 서식

| 대상 | 규칙 | 처리 |
|---|---|---|
| 항목 기호 | 1. → 가. → 1) → 가) → ⑴ → ㈎ → ① → ㉮ (대등 나열은 □ → ○ → - → •) | 자동·안내 |
| 들여쓰기 | 하위 항목은 2타(한글 1자)씩 오른쪽 | 자동 |
| 항목 하나 | 번호를 붙이지 않음 | 초안 출력 |
| 관련 근거 | 번호·날짜와 함께 「문서 명칭」, 날짜가 앞선 것부터 | 안내·초안 출력 |
| 붙임 | 하나씩 번호와 `1부.`, 묶어 쓰지 않음(`각1부` 안내), '별송'은 '따로 보냄' | 자동·안내 |
| 끝 표시 | 본문 또는 붙임 끝에 2타 띄우고 `끝.` | 자동 |

## 어법

| 대상 | 예 | 처리 |
|---|---|---|
| 높임법 | 낮춤 표지 '-오-' 대신 '-시-': `하오니` → `하니` | 자동 |
| 띄어쓰기 | `2025. 2. 28. 자`, `건축법 시행규칙`, `1년 이상`, `할 수 있다` | 자동 |
| 쌍점 | `장소: 대회의실` (앞은 붙이고 뒤는 띄움) | 자동 |
| 중첩어 | `2월달`, `매 2년마다`, `미리 예측`, `과반수 이상` | 자동 |
| 사동 | `향상시키다` → `향상하다` | 자동 |
| 기념일 | `3. 1절` → `삼일절` | 자동 |

## 표현 원칙

| 원칙 | 교정 | AI 지침 |
|---|---|---|
| 사실성 | 중첩어, 사동 | 육하원칙, 숫자 착오 금지 (AI가 숫자를 바꾸면 경고) |
| 용이성 | 쉬운 말·외래어 바꾸기, 긴 문장 안내 | 짧게 끊어 항목별로 |
| 명확성 | — | 주술 호응, 명사 나열 금지 |
| 비고압성 | `~하시오`, `엄금`, `절대` 안내 | 안내하는 긍정 표현 (`안내문` 톤) |
| 비표지성 | `불우 이웃` → `이웃` | 차별·부각 금지, 가나다순 |
| 수요자 중심 | `교부합니다`, `접수합니다` 안내 | 주어를 국민으로 |

AI 초안에는 구별해서 쓸 말(참고/참조, 주최/주관, 고시/공고, 이상/초과, 이전/전 등)과 기안문 구성 규칙(1안건 1기안, 항목 종결 어미)도 함께 지침으로 줍니다.
